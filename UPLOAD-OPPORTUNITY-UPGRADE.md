# Upload instructions

1. Extract the ZIP.
2. Upload all extracted contents to the repository root.
3. Replace existing files and preserve supplied zero-byte obsolete files.
4. Commit with: `Add high-intent opportunity calculators and guides`.
5. Run the weekly GitHub Action manually once.
6. Resubmit `sitemap.xml` in Search Console.
7. Inspect the four new calculator URLs and the five new guide URLs.
8. Wait 14 to 30 days before making widespread title changes. Use real Search Console data.
