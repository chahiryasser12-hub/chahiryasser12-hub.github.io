# Google Search Console setup for Fynzo

The code is Search Console ready, but property verification and indexing requests must be completed in the Google account that owns Fynzo.

1. Add a Domain property for `fynzo.me`.
2. Verify ownership with the DNS TXT record supplied by Google.
3. Submit `sitemap.xml` in the Sitemaps report.
4. Inspect and request indexing for the homepage and the main calculator/hub pages.
5. Review Page indexing, Core Web Vitals, HTTPS, Enhancements and Manual actions weekly.
6. In Performance, monitor clicks, impressions, CTR, position, queries and pages.

Do not add a fake `google-site-verification` token. Use only the token generated in the Fynzo Search Console property.
