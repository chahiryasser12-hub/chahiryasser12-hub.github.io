GPA Calculator

Calculate a weighted semester GPA from course credits and letter grades using a standard 4.0 scale.

How to read this result

The result uses a 4.0 grade-point scale and credit weighting. Verify the official rules used by the school.

Based on this result, you may also want to try:Calculate grade percentageOpen percentage calculator

Result breakdown

A visual summary that updates with your calculation.

GPA formula

Multiply each course grade point by its credits, add the quality points and divide by total credits.

Grade scale

Enter the grade-point value used by the institution. This calculator uses a maximum of 4.0.

Important limitation

Schools can use different scales, weighting, repeats and inclusion rules. Verify the official calculation policy.

Frequently asked questions

Is GPA weighted by credits?

+
Yes. Courses with more credits contribute more to the result.

Can I use letter grades?

+
Convert each letter grade to the grade-point value used by the institution.

Does this calculate cumulative GPA?

+
This version calculates the entered set of courses. Existing cumulative totals can be combined as another weighted block in a future update.

Is every school on a 4.0 scale?

+
No. Check the institution policy.
