# Search Console quick-win rules

After 14 to 30 days, export Queries and Pages and prioritize:

1. Position 8 to 30 with meaningful impressions.
2. CTR below the page/query expectation.
3. Query clearly answered by an existing calculator.
4. Query whose words or scenario are missing from the visible page.
5. Page receiving impressions across several closely related long-tail queries.

For each selected opportunity, change only what the query justifies: add one answer, one worked example, one FAQ, one comparison or one internal link. Avoid rewriting every title at once.
