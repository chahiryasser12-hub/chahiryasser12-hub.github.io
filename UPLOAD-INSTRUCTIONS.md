# Upload instructions

1. Extract `Fynzo-Search-Visibility-Upgrade.zip`.
2. Upload everything inside the extracted folder to the repository root.
3. Replace existing files.
4. Keep the supplied zero-byte obsolete files.
5. Commit with: `Add search visibility examples and formula tests`.
6. Run the weekly GitHub Action manually once.
7. Resubmit the sitemap in Google Search Console.
8. Inspect the priority URLs listed in `INDEXING-PRIORITY.md`.
