Quick answer

This calculator gives an instant estimate from the values entered above. Use the result as a planning starting point, then review the assumptions and limitations.

How to use the calculator

Enter the requested values using consistent units. Change one input at a time when comparing scenarios, and verify every value before using the result.

Assumptions

The estimate uses the values currently entered and the formula described on this page. Any fees, taxes, timing rules or personal circumstances not requested are excluded.

Common mistakes

  • Mixing monthly and annual values
  • Using inconsistent measurement units
  • Changing several inputs at once when comparing scenarios
  • Treating an estimate as a quote, approval, diagnosis or guarantee

What this calculator does

This tool estimates the regular contribution needed to reach a target from a current balance by a chosen date or term.

Formula used

It solves the future-value equation for the recurring contribution after accounting for the current balance and assumed periodic return.

Worked example

To build $12,000 in 24 months from zero with no interest, the required contribution is $500 per month.

How to interpret the result

The result is a planning target. A higher starting balance, longer timeline or positive return generally reduces the required contribution.

Important limitations

Returns are assumed constant, contributions are assumed to occur regularly, and taxes, fees and inflation are excluded. Actual account rates can change.
